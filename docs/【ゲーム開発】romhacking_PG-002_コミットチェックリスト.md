# 🎯 コミットチェックリスト

## ✅ コミット前に必ず確認すること

- [ ] コーディング規約に準拠しているか（命名規則、禁止事項など）
- [ ] アノテーションコメント（`TODO` / `FIXME`）が未対応のままになっていないか
- [ ] 変更したヘッダファイルにファイルコメント（作成者・日付・概要など）が記載されているか  
  - ※`template.cpp` にひな形あり
- [ ] テスト用コードやデバッグコードがそのまま残っていないか
- [ ] 一時的なコメントアウトコードや不要な古いコードが残っていないか
- [ ] 改行コードは `LF` で統一されているか  
  - ※`resource.h` など `CRLF` が必要なファイルは除外
- [ ] ビルド結果にワーニングやエラーが出ていないか
- [ ] リソースのバージョン番号（ビルド番号など）は更新されているか

---

## 💡 補足・推奨チェック項目（任意）

- [ ] `git diff` で差分に意図しない変更（空白・デバッグログなど）が含まれていないか確認したか
- [ ] `.gitignore` の適用漏れがなく、不要なファイル（*.exe、*.user、秘密ファイルなど）が含まれていないか
- [ ] コミットメッセージがルールに従って記載されているか（例：`fix: バグ修正` / `feature: 機能追加`）
- [ ] リソースの差し替え・削除がある場合、ゲーム側で正常に扱えているか動作確認済みか
- [ ] `#define DEBUG` など開発用フラグが無効化されているか
- [ ] 設定ファイル（画面サイズ、音量、セーブデータパスなど）に一時的変更が残っていないか
