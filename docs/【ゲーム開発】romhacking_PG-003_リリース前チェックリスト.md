# 🚀 リリース前チェックリスト

## ✅ メジャーバージョンコミット・リリース準備時に確認すること

- [ ] 「コミットチェックリスト」のすべての項目を満たしているか
- [ ] 単体テスト（Unit Test）がすべてクリアされているか
- [ ] メモリリークが発生していないか（ツール等でチェック済みか）
- [ ] バージョンタグが正しく付けられているか（例：`v1.2.0`）
- [ ] フレームレート・パフォーマンスが許容範囲内にあるか
- [ ] セーブデータや設定ファイルの後方互換性を確保しているか
- [ ] クレジット情報・ライセンス表記に漏れがないか
- [ ] ビルド成果物の最終確認（画面サイズ、速度、アセット整合性など）
- [ ] リリース用ドキュメント（更新履歴、既知の問題など）が添付されているか
- [ ] ブランチは `develop` → `release` → `master` の順で正しくマージされているか
